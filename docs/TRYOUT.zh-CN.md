# 首次试用：从像素图到关卡数据

建议预留 10–15 分钟。使用 Node.js 22 或更高版本，执行 `npm ci --include=dev` 和 `npm run dev` 后，打开终端里的本地地址。

## 操作路线

1. 在「像素化页面」点击「选择图片」，导入 `examples/pixel-flower.png`。它是本项目用几何图形新绘制的 24 × 24 网格，每格 10 像素。
2. 检查「处理后的网格」与原图是否一致。使用调色板选择颜色，再点网格改一格；「橡皮」可擦除为透明格。背景透明区域不计入豆子数量。
3. 点击「更新关卡预览」，向下查看拼豆资源匹配和预览。
4. 在排序选项中填写 seed（例如 `7`），点击「生成关卡排序」。查看排序前后效果和质量指标。相同输入、参数及 seed 应能复现结果。
5. 点击「下载排序 point」导出起始布局；点击「下载主体网格颜色」导出目标图。需要完整像素配置时，使用关卡预览中的「导出 pixelconfig 草稿」。
6. 使用「保存草稿」把像素图及布局保存到本地工作区。在「像素图管理」和「主线关卡管理」中，可以继续管理像素配置与关卡参数；`examples/pixelconfig.json` 和 `examples/levelconfig.json` 是另一套可直接导入的几何样例。

若图片自动识别的网格不正确，先将 Grid Size 设为 `10` 并更新网格。也可通过「选择Grid Color」导入 `examples/pixel-flower-map.json`，跳过图片识别来单独体验编辑与布局生成。

## 当前边界

- 这是本地制作工具，不是可直接游玩的游戏。
- 布局生成是启发式算法；质量未达标的候选不能当成已验证可玩的关卡。
- 完整工作区功能需要 Vite 本地服务，不能只把构建产物放到静态网站上。
- 演示使用新绘制的简单素材，不代表对任意图片的识别效果。

## 演示与预检

[60 秒截图步骤演示](https://github.com/diandongtx/pixel-dev-tool/releases/download/v0.1.0/pixel-dev-tool-walkthrough.mp4) 来自实际操作截图，并非连续录屏。演示把一个粉色格改成黄色，使用 seed 7；导出主体为 14 × 21，包含 194 颗豆子。已核对导出和保存数据的颜色数量、背景位置保持一致。

排序器的通过标志与综合质量预检不是同一套指标。此演示的综合预检仍提示结构保留度与操作数带宽问题，因此仅作为工作流草稿，不是已调优的关卡。请同时检查两处提示。
